# ⚡ GridPilot MVP

Streamlit MVP for explainable substation peak management.

## Features
- Peak-demand scenario forecasting
- Temperature, EV and solar effects
- Battery discharge optimization
- Opted-in EV charging throttling/shifting
- Substation constraint detection
- Four-strategy comparison
- Explainable scoring
- Human-in-the-loop approval
- 24-hour synthetic load visualization

## Deploy
Push to GitHub and select `streamlit_app.py` as the Streamlit Cloud main file.

## Run locally
`pip install -r requirements.txt`
`streamlit run streamlit_app.py`

**Synthetic data only. No FPL, SCADA, ADMS, DERMS or live grid control.**
